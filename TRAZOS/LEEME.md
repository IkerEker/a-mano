# TRAZOS

Aquí va todo el material real o generado para dar realismo a A mano: trazos, manchas, salpicaduras,
repasados, inicios y finales, papeles… Sin orden obligatorio: se analizan, se separan y se decide para qué sirve cada uno.

- Cualquier formato de imagen (mejor PNG o TIFF), la mayor resolución posible.
- Fondo blanco o claro; mejor sin sombras.
- Si puedes, pon en el nombre la herramienta (`boli_`, `lapiz_`, `carboncillo_`, `rotulador_`, `pincel_`, `papel_`, `mancha_`…).
  Si no, no pasa nada: se clasifican al analizarlos.
- Se pueden crear subcarpetas por herramienta si te resulta más cómodo.

Para subir desde la web: entra en esta carpeta → **Add file → Upload files** → arrastra → **Commit changes**.
